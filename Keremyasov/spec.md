# Спецификация приложения "Менеджер задач"

# 1. Главное окно
- Поле ввода для текста задачи.
- Кнопка "Добавить".
- Список задач.
- Кнопки "Удалить" и "Отметить выполненной".

# 2. Действия пользователя

# 2.1 Добавить задачу
- **Предусловие:** поле ввода не пустое.
- **Постусловие:** задача добавлена в конец списка со статусом "активная", поле ввода очищено, данные сохранены в файл `tasks.json`.
- **Инвариант:** текст задачи не пустой, список не теряет старые задачи.
- **Расширение:** если поле пустое, выводится сообщение об ошибке, список не меняется.

# 2.2 Удалить задачу
- **Предусловие:** в списке выбрана задача.
- **Постусловие:** задача удалена, данные сохранены.
- **Инвариант:** удаляется только выбранная задача.
- **Расширение:** если ничего не выбрано, выводится сообщение об ошибке.

# 2.3 Отметить выполненной
- **Предусловие:** в списке выбрана задача.
- **Постусловие:** статус задачи меняется на противоположный (выполнена/не выполнена), данные сохранены.
- **Инвариант:** статусы остальных задач не меняются.
